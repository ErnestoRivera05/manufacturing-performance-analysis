# 📊 Proyecto de Análisis de Manufactura — OEE, scrap y desempeño operativo

Este proyecto analiza el desempeño de una empresa de manufactura utilizando métricas operativas clave y su relación con el impacto económico del negocio.

Se trabaja con datos de producción, ventas y mantenimiento para evaluar:

- disponibilidad
- rendimiento
- calidad
- OEE
- scrap rate

---

## 🧭 Contexto de negocio

Aunque los niveles de producción se mantienen relativamente estables, los ingresos presentan variaciones.  
La hipótesis inicial es que existen ineficiencias internas que afectan la rentabilidad del negocio.

Este proyecto busca validar o refutar esa hipótesis utilizando datos.

---

## 🛠️ Herramientas utilizadas

- Python
- Pandas
- Matplotlib
- SQL Server
- Jupyter Notebook

---

## 📈 Resultados principales

- La disponibilidad no es el problema principal.
- A mayor rendimiento, aumenta el scrap.
- La Línea A genera mayores ingresos, pero también mayores costos por scrap.
- La Línea B, aunque vende menos, presenta mejor margen.
- La mayor oportunidad económica está en **reducir scrap**, no solo en producir más.

---

## 🚀 Recomendaciones

- Priorizar reducción de scrap en la Línea A.
- Revisar metas de rendimiento para evitar sacrificio de calidad.
- Entrenar operarios y estandarizar procesos en alta velocidad.
- Buscar velocidad óptima de operación que maximice OEE.

---

## 🧾 Conclusión

> El foco no debe ser producir más, sino producir mejor:  
> menos scrap, procesos más estables y mayor margen.
